# Análisis de Pasajeros del Titanic

## Descripción
Proyecto de análisis exploratorio de datos (EDA) para identificar las características clave asociadas a la supervivencia de los pasajeros del Titanic.

## Estructura del Proyecto
* `data/`: Dataset principal (`train.csv`).
* `src/`: Código en Python para procesamiento y visualización (`analysis.py`).
* `outputs/`: Gráficos generados.
